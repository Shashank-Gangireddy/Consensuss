Consensus — Settings

There is no default model — pick one for your provider (use "Fetch available models" after entering your API key, or type an exact model id) before analyses will work. Providers periodically retire/rename model ids, so if analysis starts failing, re-check this field.

We always fetch comments from the page (also scaled to the video's total comment count), then rank them by likes, strip duplicates/low-content noise (e.g. "lol", emoji-only), and send only the top N to the model. Auto picks N for you — bigger videos get a larger, more representative sample; small videos aren't padded with nothing. Manual pins the old fixed behavior if you'd rather control cost directly. Fewer sent = lower cost per analysis; more sent = broader coverage.
